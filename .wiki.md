# Project Summary
**AfricaVerify** is a comprehensive identity verification platform designed specifically for African nations, emphasizing government card verification. It utilizes advanced biometric authentication methods, including Passkey technology, to ensure secure access and verification of government-issued identity cards. The platform streamlines the verification process for both citizens and government officials, delivering a user-friendly experience while adhering to stringent security protocols. Recently, the project has integrated a Ghana Land Registry module, enhancing property management and role-specific functionalities.

# Project Module Description
- **Dashboard**: Central hub for user-specific features, statistics, and notifications.
- **Government Card Verification**: Validates government-issued identity cards for multiple African countries.
- **Passkey Authentication**: Implements secure biometric login using devices such as fingerprints and facial recognition.
- **Biometric Security**: Manages the enrollment and verification of various biometric modalities.
- **Africa Map Viewer**: Visual representation of verification coverage across African countries.
- **Verification Analytics**: Provides insights and statistics on verification performance and user engagement.
- **Ghana Land Registry**: A module for managing land properties with role-based user authentication, now updated to include actor review capabilities and Ghana Card verification integration.

# Project Summary
**AfricaVerify** is an innovative identity verification platform designed specifically for African nations, focusing on the authentication of government-issued ID cards. It utilizes biometric authentication methods, including advanced Passkey technology, to ensure secure and efficient verification for citizens and officials. The platform is user-friendly and adheres to high security standards. Recent enhancements include a revamped Ghana Land Registry module, integrating futuristic design elements and improved functionality.

# Project Module Description
- **Dashboard**: Central hub for user-specific features, statistics, and notifications.
- **Government Card Verification**: Validates government-issued identity cards across various African countries.
- **Passkey Authentication**: Secure biometric login utilizing devices like fingerprints and facial recognition.
- **Biometric Security**: Manages the enrollment and verification of various biometric modalities.
- **Africa Map Viewer**: Visual representation of verification coverage across African countries.
- **Verification Analytics**: Insights and statistics on verification performance and user engagement.
- **Ghana Land Registry**: Comprehensive management of land properties with role-based user authentication, actor review capabilities, Ghana Card verification integration, and enhanced user profiles.

# Project Summary
**AfricaVerify** is an advanced identity verification platform tailored for African countries, specializing in the authentication of government-issued ID cards. Leveraging biometric authentication methods, including innovative Passkey technology, it ensures secure and efficient verification for both citizens and officials. The platform is designed to be user-friendly and compliant with high security standards. Recent updates have significantly enhanced the Ghana Land Registry module, providing a modern interface and improved functionalities, including image uploads for land parcels.

# Project Module Description
- **Dashboard**: Central hub for user-specific features, statistics, and notifications.
- **Government Card Verification**: Validates government-issued identity cards across various African countries.
- **Passkey Authentication**: Secure biometric login utilizing devices like fingerprints and facial recognition.
- **Biometric Security**: Manages the enrollment and verification of various biometric modalities.
- **Africa Map Viewer**: Visual representation of verification coverage across African countries.
- **Verification Analytics**: Insights and statistics on verification performance and user engagement.
- **Ghana Land Registry**: Comprehensive management of land properties with role-based user authentication, actor review capabilities, Ghana Card verification integration, enhanced user profiles, and new image upload functionality.

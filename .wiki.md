# Project Summary
The Decentralized Land Registry Platform is a blockchain-based solution aimed at improving land ownership verification and registration, as well as dispute resolution. It provides a secure and transparent system that benefits landowners and authorities, particularly in developing regions where traditional systems may fall short. The platform leverages smart contracts to automate ownership transfers and facilitate dispute resolution, fostering an efficient and fair approach to land management.

# Project Module Description
- **Dashboard**: Provides an overview of land records, disputes, and transfers.
- **Land Registry**: Handles registration and management of land parcels.
- **Ownership Transfer**: Facilitates secure land ownership transfers using smart contracts.
- **Dispute Resolution**: Employs a community-driven method for resolving land disputes.
- **Smart Contract Interface**: Interacts with deployed smart contracts.
- **User Profiles**: Displays user information, reputation scores, and activity history.
- **User Authentication**: Supports user authentication with options for different countries, including automatic country detection.

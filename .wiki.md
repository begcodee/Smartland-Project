# Project Summary
**AfricaVerify** is a modern government card verification platform designed to enhance identity verification across multiple African nations. By integrating advanced biometric authentication methods, including Passkey technology, it ensures secure access and verification of government-issued identity cards. The platform aims to simplify the verification process for citizens and government officials, providing a seamless user experience while maintaining high-security standards.

# Project Module Description
- **Dashboard**: Central hub displaying user-specific features, statistics, and notifications.
- **Government Card Verification**: Validates government-issued identity cards for multiple African countries.
- **Passkey Authentication**: Implements secure biometric login using devices such as fingerprints and facial recognition.
- **Biometric Security**: Manages the enrollment and verification of various biometric modalities.
- **Africa Map Viewer**: Visual representation of verification coverage across African countries.
- **Verification Analytics**: Provides insights and statistics on verification performance and user engagement.
